# Security Policy

## Supported versions

Only the [latest release](https://github.com/47Hunter47/ISEL-to-Gcode-Converter/releases/latest)
is supported. Update to it before reporting — fixes ship as patch releases.

## Reporting a vulnerability

Report privately via the **"Report a vulnerability"** form:
<https://github.com/47Hunter47/ISEL-to-Gcode-Converter/security/advisories/new>

This tool generates G-code that a CNC milling machine executes
unsupervised, so findings about toolpath or feed-rate output — not just
classic memory bugs — count as security issues here. Expect a first reply
within a few days.
